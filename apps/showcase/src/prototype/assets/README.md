# Material arquitetônico — origem e derivação

`terra-material-reference.png` preserva os bytes do material da base aprovada (1672 × 941). A conferência do arquivo atualmente fornecido como 05_background_login_aprovado.png encontrou outra codificação PNG, mas todos os pixels RGBA iguais; não são arquivos byte a byte idênticos. Origem declarada pelo titular: geração no ChatGPT / OpenAI. Permissão específica registrada em 21/10/2026; sem licença geral de reutilização. Composição, máscaras e enquadramentos CSS são originais do projeto; o fundo não é SVG procedural.

`terra-material-reference.webp` é uma derivação WebP lossless VP8L produzida localmente por Canvas/Chromium, sem dependência adicional.1.421.410 bytes versus2.038.789 bytes do PNG, redução30,28%. Os pixels RGBA decodificados foram comparados integralmente no Chromium e são idênticos; a identidade visual não foi redesenhada. O PNG continua como fonte de recuperação, sem entrar no build; o build usa um único WebP compartilhado por seções/rotas.

Nenhuma das imagens herda a MIT do código. Inclusão no repositório, exibição no Pages e conversão WebP preservando aparência foram autorizadas expressamente pelo titular para Terra Motion Skills. Registro: docs/ASSET_RIGHTS.json e ASSET_NOTICES.md na raiz. Logo possui arquivo/aviso separado.
